# 🏋️ Fitness Analytics Dashboard

## 📊 Project Overview

This project presents an interactive **Fitness Analytics Dashboard** developed using Power BI.

The dashboard is designed to analyze fitness business performance by tracking **clients, trainers, memberships, revenue, expenses, profit, and monthly membership trends**.

The main objective of this project is to transform fitness business data into meaningful insights and support data-driven decision-making.

---

## 🎯 Project Objectives

* Analyze overall fitness business performance
* Track total clients and trainers
* Monitor revenue, expenses, and profit
* Analyze membership performance
* Compare active and expired memberships
* Analyze Platinum, Gold, and Silver memberships
* Track monthly membership trends
* Monitor client activity and completed days
* Create an interactive and user-friendly dashboard

---

## 📈 Dashboard Features

### 💰 Financial Analysis

The dashboard provides monthly analysis of:

* Revenue
* Expenses
* Profit

It helps understand the financial performance and identify monthly trends.

### 👥 Membership Analysis

Memberships are analyzed based on:

* Platinum
* Gold
* Silver
* Active memberships
* Expired memberships

### 📅 Monthly Members Analysis

The dashboard provides a month-wise view of member activity and helps identify months with higher or lower membership levels.

### 🏃 Client Activity Analysis

The dashboard tracks:

* User Name
* Remaining Days
* Completed Days

This helps monitor individual client activity and membership usage.

## 💡 Key Insights

* The fitness business has **100 clients** and **20 trainers**.
* Total revenue is **4.1M**.

* Membership performance can be compared across Platinum, Gold, and Silver plans.
